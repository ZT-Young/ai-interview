# docs/samples —— 本地手工测试样本（**本目录内容不入库**）

这里存放开发期用来**手工验证简历解析链路**的真实简历。它们含有真实手机号与邮箱，
属于个人敏感信息，已被 [../../.gitignore](../../.gitignore) 的 `/简历_*` 规则排除，**不会提交到仓库**。

## 为什么这个目录在 git 里是空的

因为这些文件不该公开。所以：

- 本目录只入库 `README.md`（你正在读的这份）和 `.gitkeep`
- 简历文件本身永远留在本地，clone 出来的人看到的是一个带说明的空目录
- 团队协作或 CI 环境需要样本时，**用程序化夹具**，见
  [../../tests/fixtures/documents.ts](../../tests/fixtures/documents.ts) —— 它能现场生成 PDF / DOCX，
  不含任何真实个人信息

## 怎么用

在浏览器里走「简历 → 上传文件」时选择本目录下的文件，用来验证：

| 样本 | 用途 |
| --- | --- |
| `简历_v1_AI测试开发工程师.md` … `简历_v4_测试开发工程师.md` | 纯文本型简历，验证文本抽取与结构化解析 |
| `简历_v5_雀巢技术培训生.md` / `.html` | 验证 `.md` 与 `.html` 两种格式的抽取差异 |

## 注意

- **不要把这里的文件 `git add -f` 上去**。仓库侧有两道自动检查会拦：
  `scripts/check-secrets.mjs` 与 `scripts/audit-public.mjs`（`pnpm audit:public`）。
- 代码与测试**没有任何地方引用**本目录的文件，删除它们不影响 `pnpm test` / `pnpm build` 的任何结果。
- 新增样本请沿用 `简历_*` 命名前缀，这样才会被 `.gitignore` 自动排除。
