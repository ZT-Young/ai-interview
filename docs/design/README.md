## 落地时的约定

- 基础组件放 `components/ui/`（shadcn/ui 风格，无业务语义）；业务组件放 `components/features/<领域>/`。
  判断标准：**换个项目还能不能直接用**——能就是 `ui/`，不能就是 `features/`。
- 视觉基线（颜色 token、圆角、阴影）在 `app/globals.css` 与 `tailwind.config.ts`，
  本文档描述规格，**不复制具体色值**，避免两处漂移。
- 状态设计是**硬要求**：每个页面必须有空的、加载中的、出错的三种状态，
  不能只做成功态。见 [UI.md](./UI.md) §3。
